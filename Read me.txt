.# Techsewa - Setup Guide (Command Prompt)

## Requirements

- Python 3.8 or above installed  
  Check with:
python --version

h ggg
- Microphone and speakers connected

---

## How to Install Required Python Packages

1. Open **Command Prompt** (Press `Win + R`, type `cmd`, hit Enter)

2. Run the following commands one by one:
pip install tkinter  
pip install pillow  
pip install pyttsx3  
pip install requests  
pip install psutil
pip install matplotlib  
pip install sv-ttk  
pip install ping3 
pip install fuzzywuzzy  
pip install playsound  
pip install python-Levenshtein  
pip install pyinstaller  
pip install autopep8  
pip install pillow pyttsx3 requests psutil matplotlib sv-ttk ping3 fuzzywuzzy gTTS playsound python-Levenshtein
---

## How to Run Techsewa

1. Navigate to your Techsewa folder in Command Prompt:

F:
cd Techsewa



2. Run the main app:

python ui.py
